# License audit

PASS for exact shared Diriqo Office lockfile SHA-256 fb76056a8bbe6cb0cd63a3f47912063a25bd967b96201b03aad140176907e09e. 130 packages inspected. This is technical license evidence checking, not legal advice or legal immunity.

Every artifact SRI, identity, declared license and preserved LICENSE/COPYING/NOTICE was checked. Third-party notice files and inline copyright blocks were also preserved and screened for known excluded terms. Pinned official upstream evidence is used only for exact reviewed packages that omit full license text in npm artifacts; content hashes and source URLs are retained. jstat1.9.6 uses its exact archived legacy licenses array and MIT LICENSE because npm omits the modern license field. esbuild0.28.2 platform binaries contain Go1.26.5; Go runtime/vendor BSD and xxhash MIT notices are included. Allowed identifiers: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, 0BSD, CC0-1.0, OFL-1.1. OR selects an allowed branch; AND requires every branch. Unknown or missing evidence fails closed.

Scope: the new Office package only, including transitive and build dependencies; existing host application dependencies are outside this audit. No package installed by this script.

CI --check fails for changed dependency declarations, lockfile, resolution, integrity, evidence or generated reports. Regenerate preflight before installation, then review the evidence diff. Text markers are a conservative consistency check, not legal interpretation of bundled third-party notices.

Assets: one unmodified Geist Regular 1.800 font is bundled for server PDF export under SIL OFL 1.1. Exact font and full OFL bytes, hashes, pinned upstream URLs and copyright are retained in licenses/assets/evidence.json and ASSET_LICENSES.md. CI validates those bytes and embedded server data. UI continues to use system fonts; dependency controls/icons retain their notices. Customer uploads remain customer content.

Excluded: Univer was rejected because ot-text-unicode4.0.0 has contradictory ISC metadata and an incomplete MIT grant in README; older versions tested had the same discrepancy. TypeScript5.9.3 was not added because its embedded ThirdPartyNoticeText includes Unicode, W3C and CC-BY material outside this strict allowlist. Existing host compiler may be used separately without adding it to this package. ExcelJS, Mammoth and docx were assessed but their resolved dependency trees introduced license identifiers outside the requested strict allowlist (including Unlicense, Zlib or BlueOak). Their permissive top-level license alone was insufficient. PDF candidates pdf-lib1.17.1 plus fontkit1.1.1 and jsPDF4.2.1 were rejected at their pako1/2 dependency paths: MIT AND Zlib requires the excluded Zlib license. PDFKit0.20.2 was considered but its full graph was not approved; its older pako0.2.9 has MIT metadata and LICENSE, so it is not represented as a proven Zlib blocker. These candidates were not installed; a passing full-graph audit is not claimed. See licenses/pdf-candidates.json. The bounded PDF serializer is original project code using the public PDF/OpenType specifications. Office uses original bounded OOXML/OpenDocument text adapters and legacy DOC text recovery based on public format specifications, with explicit fidelity limits; DOC export is not offered. SheetJS Community Edition 0.20.3 (Apache-2.0) supports the spreadsheet conversion adapters. It has no npm runtime dependencies and is pinned to the exact official cdn.sheetjs.com artifact, SHA-256 8dc73fc3b00203e72d176e85b50938627c7b086e607c682e8d3c22c02bb99fe8 and its independently derived SHA-512 integrity. The archive SHA-256 is checked before archive parsing, and its LICENSE files and inline copyright notices are preserved. No general CDN resolution or SheetJS Pro component is approved.

No paid editor SDK is allowed; runtime telemetry/network behavior requires browser validation separately. Ship THIRD_PARTY_LICENSES.md, LICENSE_AUDIT.md, licenses/ and sbom.cdx.json together.
